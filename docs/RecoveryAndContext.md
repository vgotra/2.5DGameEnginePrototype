# Recovery and Context

Every milestone updates `.agents/context/CurrentState.md`, `NextSteps.md`, `Decisions.md`, and `KnownIssues.md` (plus `FilesMap.md` when files are added/renamed), and adds an entry to `RELEASE_NOTES.md`. Each update records changed interfaces, tests, benchmark results, and the next three actions. ADRs capture decisions that affect module boundaries or external dependencies.
