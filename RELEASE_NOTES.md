# Release Notes

## 2026-08-03
- Migrated the Win32 P/Invoke surface to source-generated `[LibraryImport]` (roadmap item 14): `NativeMethods.cs` (20 declarations) + `Win32Types.cs` replace the private `[DllImport]`s in `Win32Window.cs`/`Win32Input.cs` for AOT/trim safety. UTF-16 string APIs pin explicit `W` entry points with `StringMarshalling.Utf16`; `PeekMessage`/`DispatchMessage`/`CallWindowProc` are pinned to their `A` variants (no literal export in `user32.dll`); `TranslateMessage` is literal-only; `GetWindowLongPtrW` returns `nint`; the WndProc delegate callback is preserved. 0 warnings; launch probes exit code 0.
- Implemented roadmap item 1 — stable game loop and window lifecycle (`docs/FramePacingPlan.md`): `Engine.Core.FrameTimer` (high-res `Stopwatch` dt, optional `--cap <fps>`, default unpaced) replaces `Environment.TickCount64` + `Thread.Sleep(2)`. Swapchain prefers MAILBOX (fallback FIFO) with triple buffering; a 3-slot frame-in-flight pool + per-swapchain-image fences overlap frames; staging→device copies are recorded into the main command buffer behind a `TRANSFER → VERTEX_INPUT` barrier with an FNV dirty gate (no per-frame `vkQueueWaitIdle`); `ErrorOutOfDateKHR` rebuilds the swapchain; ESC/window close tears down cleanly. Updated `docs/` and resumable context.
- Improvement-set recheck (2026-08-03): ECS purge semantics + recycle-safe re-`Add` (generation bump, `ISparseSet.Remove` swap-with-last); `.editorconfig`; Release solution mappings for all 13 projects; pinned u8 shader/instance names; Debug-only Vulkan validation layers; `FrameTimer` sleep+spin residual; doc corrections D1-D10. Verified Debug+Release 0-warning builds, smoke tests, and `--cap 60` launch/clean-exit probe.
- Threading audit + `JobSystem` drain fix (2026-08-03): `DrainAsync` blocks on a `SemaphoreSlim` completion signal (Interlocked pending counter) instead of busy-waiting; `Engine.Tests` covers it. A runtime probe confirmed the Thread/Task surface on .NET 10.0.10 (`Lock`, `Task.WhenEach`, `TimeProvider` present; `SemaphoreSlim.WaitAsync(TimeProvider)` and `ThreadPool.GetQueueCapacity/SetQueueCapacity` absent — never shipped). `FrameTimer` intentionally unchanged.
